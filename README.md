## How to Use

Each project is self-contained and has its own `README.md` and `requirements.txt`.

Typical setup:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

Then:

```bash
pip install -r requirements.txt
```

Follow the individual project's README for its run command.
